# 方記 AI 營運副手示範資料

> **重要聲明：本目錄全部內容均為虛構合成資料，僅供非官方技術示範；不代表任何真實人物、公司、工程或報價，亦不構成工程、安全、法律、環境、財務或其他專業意見。**

## 資料原則

- 公司、人名、地址、電話、電郵、合約、相片及數字均屬虛構。
- 不收錄香港身份證、銀行帳戶、真實聯絡資料或可識別個人的自由文字。
- 危險物料、結構安全及法規問題只提供升級處理流程，不由 AI 下結論。
- `visibility` 用於權限隔離；檢索層必須在搜尋前套用角色篩選。
- 文件中的金額皆為示範估算，正式報價須由獲授權人員覆核。

## 檔案

- `company-handbook.md`：服務、工作流程、報價與通用安全規則。
- `synthetic-projects.md`：三個完全虛構的項目個案。
- `access-control.md`：角色、資料可見範圍及拒答要求。
- `queries.jsonl`：可供匯入或人工測試的合成查詢。

## 建議 metadata

匯入向量庫時保留 `document_id`、`section_id`、`visibility`、`source_type`、`synthetic=true`。回覆引用格式應至少包含 `document_id#section_id`，而且只可引用實際取回且使用者有權查看的段落。
